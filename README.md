# Pharmacovigilance Internship - Task 1
## ADR Identification Basics

**Prepared by:** Yogesh Kumar  
**Programme:** B.Pharm | Raj Kumar Goel Institute of Technology (AKTU)  
**Case type:** Fictional educational training case

### Project objective
This repository demonstrates a structured approach to identifying a suspected adverse drug reaction (ADR), reviewing the medicine-event timeline, considering alternative explanations, documenting dechallenge/rechallenge information, and presenting the reasoning in a professional case-report format.

### Repository structure
```text

```

### What the PDF contains
- Pharmacovigilance foundations
- AE vs ADR distinction
- Type A-F ADR overview
- An original fictional ADR case
- Medicine/event timeline
- Suspected medicine assessment
- Causality reasoning using the factors highlighted in the training task
- ADR reporting fields and India reporting pathway
- Key takeaways and quality checklist
